# AHC Responsive Review Notes

**Review date:** August 2026  
**Viewports inspected:** 375 × 812 phone viewport and 1280 × 720 desktop viewport.

The public marketplace preserved readable hierarchy, controls, video framing, map content, and trust disclosures at phone width without visible horizontal overflow. The desktop home page also retained its structured hero/search relationship and accessible action emphasis.

The protected Field Moderator and Admin sign-in routes kept their forms legible and reachable at both inspected sizes. The review identified a useful consistency improvement: those staff access routes should carry more of the Courtyard Atlas identity and use stronger small-screen spacing so they feel part of the same product system while retaining their intentionally private, functional purpose.

The responsive pass will therefore preserve the existing public layout, add branded staff-access framing, improve touch-sized visual controls, and retain the existing one-column small-screen form behavior. The printable receipt has its own 520 px small-screen layout and dedicated A4 print rules.
