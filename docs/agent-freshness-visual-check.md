# Agent Listing Freshness Visual Check

## Desktop, signed-in paid Agent

On 13 August 2026, the non-production Ebot paid-Agent workspace was reviewed after local AHC sign-in. Each inventory card displayed a read-only clock-labelled freshness line beneath its status and Total Move-In Cash figure. The line showed the recorded reconfirmation date and a **14 days remaining** countdown for the verified Bastos, Jouvence, and Mvan fixtures; the pending Biyem-Assi fixture showed the same read-only status without gaining publication privileges.

The action controls remained unchanged: published listings retained **Reconfirm**, **Feature pin**, and **Verify** controls, while the information line did not alter listing state or reveal private moderator evidence.
