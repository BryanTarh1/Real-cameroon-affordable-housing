# Viewing Appointment Concierge Validation

**Validation date:** 13 August 2026

The public marketplace was reviewed at desktop (`1280×720`) and mobile (`375×812`) widths after the viewing appointment concierge was added. The signed-out view retains the existing Courtyard Atlas hierarchy and keeps appointment request capability inside the protected property-detail journey. The Agent-side concierge uses a separate responsive queue layout with contact data withheld until the Agent confirms a request. A signed-in test account with a physically verified live fixture is still required for an end-to-end visual confirmation of the request form and Agent status controls.
