# Cloudflare Turnstile integration research

AHC will use Cloudflare Turnstile for the sign-in and safety-report request boundaries, subject to the owner supplying production credentials. Cloudflare’s implementation guidance states that browser-side rendering is not sufficient: every submitted token must be sent to the server and validated by `POST https://challenges.cloudflare.com/turnstile/v0/siteverify` with the provider-issued secret and the visitor token. Tokens expire after five minutes and are single-use, so replayed or late tokens must fail rather than be accepted. A production secret must stay server-side; the browser receives only the public site key.

For deterministic automated tests, Cloudflare documents separate dummy keys. The always-pass visible test site key is `1x00000000000000000000AA` and its matching server key is `1x0000000000000000000000000000000AA`; these keys are for development and testing only and must never be used to secure the production deployment. AHC should use a real production Turnstile widget configured for `affordableho-8aahm5dj.manus.space` before treating the guard as live.

The widget reports Cloudflare code `110200` on a hostname that is not authorised for its site key. Therefore, the owner must add the public deployed hostname above in the Turnstile widget’s **Hostname Management** list. A temporary Manus preview hostname such as `3000-i8fjl6a9e68jyfwtbi6th-176f83cc.us3.manus.computer` may be added only when that preview itself needs interactive CAPTCHA testing; its random prefix can change, so it is not a durable production hostname. Until a browser hostname is authorised, AHC intentionally leaves each CAPTCHA-protected submit button unavailable and the server continues to reject any bypass attempt.

Sources: [Cloudflare, Validate the token](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/); [Cloudflare, Test your Turnstile implementation](https://developers.cloudflare.com/turnstile/troubleshooting/testing/); [Cloudflare, client-side error codes](https://developers.cloudflare.com/turnstile/troubleshooting/client-side-errors/error-codes/).
