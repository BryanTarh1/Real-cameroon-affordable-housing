# Public Trust Signals Validation

The public marketplace was reviewed on 18 August 2026 at desktop (`1280×720`) and mobile (`375×812`) viewports. The desktop entry layout remained legible, while the mobile layout preserved the media-first listing flow, prominent Total Move-In Cash overlay, ownership callout, and distinct freshness signal without horizontally crowding card actions.

Landmark privacy remains enforced in the shared server helper: submitted map radii are clamped to **200–500 m**, and public map points are shifted away from the submitted compound reference. The public map now also names the same privacy band in its bilingual map key and popup, while showing the stored listing radius rather than calculating a client-side point.

Crawler metadata is covered by a direct OpenGraph document regression. A live crawler-route response for a published non-production listing remains part of the release verification; the response must include a PNG share card, approximate landmark location, total move-in cash, and only the persisted verification and declared supply-capacity facts.
