# Field Moderator Commission Acceptance Note

The protected `/#/operations` workspace renders **Your verification commission status** as section 05, after **Random second-visit audits** and before **Private evidence history**.

The section is read-only. When a Field Moderator has no eligible allocations, it states that no verification commission allocations have been created and that no payout action is available. If allocations exist, the page shows the recorded status, evidence-review note, and timestamps; it does not expose any payment approval action. Documented Admin approval remains required before an allocation can move to payment.
