TESTING BOUNDARY

What this local version deliberately does not do

No account actions. Sign-in, account creation, payment orders, verification evidence, and staff operations remain in the protected main AHC application.

No direct contact. Phone numbers, WhatsApp destinations, private property photos, exact compound doors, and owner or Agent identities are excluded.

No production writes. The local importer only downloads an approved public-data snapshot. The web page only reads the isolated local MySQL table.
